Proyecto Integrador

Sistema Web de Gestión Integrada

Este proyecto consiste en una aplicación web completa desarrollada con Django y maquetada con HTML y Tailwind CSS. Utiliza MySQL en la nube para administrar la información de forma persistente. Permite a los usuarios autenticados iniciar sesión y gestionar un catálogo dinámico mediante operaciones CRUD (crear, ver, editar y eliminar sus propios registros) de manera segura y eficiente.
